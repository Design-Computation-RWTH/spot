# SPOT – Space Types Ontology

This repository hosts the ontology source file and documentation for the SPOT ontology.

The SPOT extensions are maintained in separate repositories:

- **SPOT-AM – Axis Mapping Extension** (`https://w3id.org/spot/am#`): [Design-Computation-RWTH/spot-am](https://github.com/Design-Computation-RWTH/spot-am)
- **SPOT-SG – Scene Graph Extension** (`https://w3id.org/spot/sg#`): [Design-Computation-RWTH/spot-sg](https://github.com/Design-Computation-RWTH/spot-sg)

---

## Repository Contents

- **Ontology Source** – OWL source file (Turtle format) for the SPOT core ontology
- **Documentation** – Supporting documentation for the ontology (source for the documentation website)
