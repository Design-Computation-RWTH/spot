Ontology Specification Draft

Abstract

The Space Types Ontology (SPOT) is an OWL-based ontology for spatially representing and managing resources and data related to assets in the built environment. Built on the principle that all asset data carries an inherent spatial dimension, SPOT provides machine-readable expressions of spatial metadata and relationships, enabling querying and integration of heterogeneous data sources across an asset. Its modular design focuses on basic spatial types and simple relationships, allowing domain-specific extensions for more precise use cases. The SPOT Ontology is extended with the SPOT Axis Mapping Ontology .

Introduction back to ToC

TheSpace Types Ontology (SPOT) provides a machine-readable, OWL-based representation of spatial metadata and relationships across an asset. It is built on the principle that all asset-related data carries an inherent spatial dimension. Even non-geometric data such as textual reports can be spatially contextualized through their references to specific components, zones, or areas. By establishing a common digital space for all asset data, SPOT enables the discovery of relationships between previously disconnected resources, supporting spatial querying and data integration.

SPOT follows a modular design, focusing on a minimal set of basic spatial types and relationships to enable broad applicability. It can be extended or combined with existing ontologies to support more precise, domain-specific use cases.
